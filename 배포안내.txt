────────────────────────────────────────
1. 올리는 법
────────────────────────────────────────
이 폴더 안의 내용물을 통째로 웹서버에 올리면 됩니다.
폴더 구조를 그대로 유지해야 이미지가 보입니다.

  Vercel  : vercel.com/new 에서 이 폴더를 드래그
  학교서버 : FTP 로 폴더째 업로드
  GitHub  : 저장소에 올린 뒤 Pages 활성화

시작 페이지는 index.html 입니다.

────────────────────────────────────────
2. 올리기 전에 꼭 할 일
────────────────────────────────────────
아래 파일에서 https://example.vercel.app 을
실제 주소로 모두 바꿔 주세요. (에디터 전체 바꾸기 사용)

  robots.txt          Sitemap 줄
  sitemap.xml         <loc> 6곳
  6개 HTML            canonical / og:url / og:image

────────────────────────────────────────
3. 파일 구성
────────────────────────────────────────
  index.html          메인
  program.html        01 프로그램 소개
  education.html      02 교육 내용 및 일정
  lineup.html         03 라인업
  apply.html          04 신청 페이지
  goods.html          05 굿즈 소개
  styles.css          공용 스타일 (6개 페이지 공유)
  images/             이미지 15개
  robots.txt          검색엔진 안내
  sitemap.xml         Google Search Console 제출용
  vercel.json         Vercel 캐시 설정 (다른 서버면 지워도 무방)

전체 용량 약 6.8MB · HTML 각 13~21KB

────────────────────────────────────────
4. 배포 후 검색 노출
────────────────────────────────────────
  1) Google Search Console 에 주소 등록 · 소유권 확인
  2) 사이트맵 메뉴에 sitemap.xml 제출
  3) URL 검사에서 페이지별 색인 요청
  4) 도서관 홈페이지 공지사항에서 링크 걸기
